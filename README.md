# Projeto-Sistema-Musical
Projeto desenvolvido em equipe para criação de um sistema web com telas de login, menu principal, cadastro de criadores, cadastro de obras e listagem, utilizando HTML e CSS com layout responsivo.


#  Sistema Musical


##  Sobre o Projeto
O Sistema Musical é um projeto desenvolvido com o objetivo de organizar e facilitar o gerenciamento de músicas e artistas. O sistema permite que o usuário faça login, cadastre artistas, cadastre músicas e visualize as músicas cadastradas.


##  Funcionalidades
O projeto possui as seguintes telas:


**Login:** acesso ao sistema.
**Menu (Index):** página inicial com acesso às funcionalidades.
**Cadastro de Artista:** permite cadastrar os criadores das músicas.
**Cadastro de Música:** permite adicionar novas músicas ao sistema.
**Listagem de Músicas:** exibe as músicas cadastradas.
##  Design e Responsividade


Arquivo único styles.css para a estilização das páginas.
Paleta de cores definida no :root do CSS.
Layout responsivo, adaptado para computadores e celulares.
Interface organizada e de fácil utilização.
##  Tecnologias Utilizadas
HTML5
CSS3
JavaScript (se utilizado no projeto)

##  Estrutura do Projeto

login.html – Tela de login.
index.html – Página inicial e menu.
cadastro_artista.html – Cadastro de artistas.
cadastro_musica.html – Cadastro de músicas.
listagem.html – Listagem de músicas.
styles.css – Estilização de todas as páginas.
##  Equipe

Desenvolver um sistema web para praticar os conhecimentos de desenvolvimento de páginas, organização de arquivos, estilização com CSS e criação de interfaces responsivas.
